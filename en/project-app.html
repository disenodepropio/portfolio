UX UI Project

Mobile Application

App for active network testing: full UX/UI design in light and dark mode, statistics system, smart scheduler and its own visual identity.

Project objective

  • ○Design a technical app that was both precise and accessible for any user.
  • ○Enable network analysis over time through statistics and scheduled tests.
  • ○Build a differentiated visual identity within the network apps ecosystem.
Year 2024
Duration 7 months
Role UX UI Design

One app, three pillars

It's not just a speed meter. It's a complete diagnostic tool built for technical users and for anyone who wants to truly understand how their network behaves. Each module has a clear purpose and an interface designed to keep the analysis uninterrupted.

1.
Active tests

Real-time network tests with clear, immediate results. The core of the app: measures download speed, upload speed, latency and jitter in seconds.

  • Download and upload speed
  • Latency and jitter
  • Real-time visual indicators
2.
Stats & Overview

Full test history in a single dashboard. Aggregated charts and metrics that reveal patterns, performance drops and network evolution over time.

  • Aggregated view of all tests
  • Trend and comparison charts
  • Filter by date and network type
3.
Scheduler

Schedule automatic tests at whatever frequency you need. The app runs tests in the background and accumulates data without user intervention, generating insights over time.

  • Flexible test scheduling
  • Automatic background execution
  • Continuous data without intervention

Designed for any environment

Field technicians work in very different conditions: low-light indoors, direct sunlight outdoors. The app adapts to all of them with two fully designed display modes.

Light mode Dark mode
